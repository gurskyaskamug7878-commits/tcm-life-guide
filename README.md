## 🇨🇳 中文介绍

### 为什么做「知常中医」？
许多现代人对中医充满好奇，但面对晦涩的古文医书或流水线式的开药处方却无从下手。**知常中医** 坚持**“明医理、找准穴、练导引”**，把复杂的传统医学转化为普通人一看就懂、打开手机就能跟着做的居家保健指南：

* **🩺 常见病痛透彻拆解**：
  * **感冒寒热辨证**：对比风寒感冒（寒锁毛孔 → 生姜葱白发汗）与风热感冒（积热上攻 → 桑菊薄荷清热），避开盲目吃苦寒中成药的误区。
  * **常见皮肤问题**：剖析湿疹、荨麻疹、痘痘（痤疮）背后的脾虚湿盛与风血郁热根源，提供饮食忌口清单。
  * **肾虚阴阳与前列腺养护**：讲透肾阴虚与肾阳虚的区别（六味地黄丸避坑），详述 **40℃~42℃ 温水坐浴理疗**及备孕人群水温安全警示。
* **📍 高精度 SVG 矢量穴位定位图鉴**：
  * 内置 **太溪、涌泉、关元、大椎、合谷、风池、足三里、神门** 8 大常用穴解剖定位图，带**动态脉冲红点标注**、一秒找穴口诀、按揉手法及孕妇禁忌提醒。
* **🧘 八部金刚功跟练馆**：
  * 完整收录道家张至顺道长公开传授的八部金刚功全八式口诀与动作分解，内置**智能语音带练计时器**（可选 3 遍 / 5 遍 / 9 遍自动报幕）。
* **🧭 今日症状辨证自测 & AI 语音讲解**：
  * 勾选当前身体信号，自动匹配对应的食疗茶饮、穴位与练功招式；全站支持点击收听中文语音播报。

## 🇬🇧 English Overview

**ZhiChang TCM Guide** is an open-source, mobile-friendly Traditional Chinese Medicine (TCM) lifestyle & self-care reference designed for everyday users. Zero backend, zero tracking, and 100% static deployment on GitHub Pages.

### ✨ Key Highlights
* **Plain-Language Syndrome Differentiation**: Clear comparisons between Wind-Cold vs. Wind-Heat colds, Eczema/Urticaria/Acne root causes, Kidney Yin vs. Yang deficiency, and Prostate warm sitz bath therapy (`40°C–42°C`).
* **Interactive SVG Acupoint Atlas**: High-precision anatomical SVG illustrations with animated pulse markers for **Taixi (KI3), Yongquan (KI1), Guanyuan (CV4), Dazhui (GV14), Hegu (LI4), Fengchi (GB20), Zusanli (ST36), and Shenmen (HT7)**.
* **Eight Sections of Vajra Longevity Kung Fu (八部金刚功)**: Complete 8-form movement breakdowns with an interactive **Voice-Guided Practice Timer** (Web Speech API).
* **Contributor-Friendly Data Layer**: All medical/wellness entries live in `data.js` for effortless community Pull Requests.

### ⚠️ Medical Disclaimer
All content in this repository is strictly for educational, cultural, and daily wellness reference purposes only. It does **not** constitute professional medical diagnosis, prescription, or clinical treatment. Always consult a licensed physician for acute or severe symptoms.
