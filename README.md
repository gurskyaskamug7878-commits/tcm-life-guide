## 📌 项目简介
**知常中医** 是一个面向现代普通人（尤其是久坐上班族、亚健康人群及家庭用户）的实用中医文化与日常养生指南。
网站摒弃晦涩难懂的古文堆砌，侧重于**“明医理、找准穴、练导引”**：

1. **常见病痛透彻拆解**：
   - 清晰对比**风寒感冒**（寒锁毛孔 -> 生姜葱白发汗）与**风热感冒**（积热上攻 -> 桑菊薄荷清热），避免乱吃药。
   - 深度解析**湿疹、荨麻疹、痘痘（痤疮）**背后的脾虚湿盛与风血郁热根源，提供饮食忌口清单与居家护理。
   - 新增**肾虚阴阳辨证（六味地黄丸避坑）**与**前列腺 40℃~42℃ 温水坐浴养护指南**。
2. **高精度 SVG 矢量经络穴位图鉴**：
   - 内置 8 大常用穴解剖位置示意图（**太溪、涌泉、关元、合谷、风池、迎香、足三里、神门**），带**动态脉冲红点定位**、一秒找穴口诀、按揉手法及安全禁忌提示。
3. **八部金刚功跟练馆**：
   - 完整收录道家张至顺道长公开传授的**八部金刚功**全套八式口诀、调理脏腑与动作要点。
   - 内置**智能语音带练计时器**（支持 3 遍体验 / 5 遍日常 / 9 遍完整版自动报幕）。
4. **今日症状辨证自测 & AI 语音讲解**：
   - 勾选当前身体信号，自动匹配对应的食疗茶饮、温水坐浴、穴位与金刚功招式；全站支持点击按钮收听中文语音讲解。
